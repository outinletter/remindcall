# RemindCall

전화를 걸기 전과 통화 중에 상대방의 번호, 생일, 메모, 연락 기록을 카드로 확인하는 iOS 앱입니다.

Shows a person's number, birthday, notes, and contact history as a card before and during calls. (iOS 17+)

## 기능 / Features

- 연락처 검색(이름, 번호 뒷자리, 초성)과 카드 화면
- 키패드에 번호를 누르면 일치하는 연락처 표시
- 즐겨찾기, 메모, 태그, 생일 D-day
- 표시할 정보와 순서를 직접 설정
- 선택 기능(설정에서 켜기): 통화 후 메모 알림, 생일 알림, 모르는 번호 이름표
- 앱 데이터는 사용자의 개인 iCloud로 동기화되며 개발자 서버를 사용하지 않습니다.
